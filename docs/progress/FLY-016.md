**Decisions made, do not re-litigate:**

- `@serwist/next` 9.5.12 is a **webpack plugin**. It does not run under Next 16
  Turbopack production builds. Do not add `@serwist/turbopack` without a catalog
  pin and ADR. Production uses `next build --webpack`; `next dev --turbopack`
  keeps the worker off (`disable` when `NODE_ENV === "development"`).
- `start_url` is `/pl`, not `/`. Locale prefix is always-on.
- Do not lock `orientation` to portrait.

**Rejected:**

- Adding `@serwist/turbopack` / `@serwist/cli` / `esbuild` to the catalog this
  PR. Task and ADR 0001 name `@serwist/next` 9.5.12.
- Using `defaultCache` as-is. Its image and cross-origin `NetworkFirst` rules
  would cache OSM `.png` tiles.

**Watch out:**

- `.gitignore` root `public/sw.js` does **not** match `apps/web/public/sw.js`.
  Both patterns must stay.
- `pnpm lint` lints `public/sw.js` unless ESLint `globalIgnores` lists it.
  Build runs before lint in `pnpm verify`, so the file exists.
- Do not commit `apps/web/next-env.d.ts` when Next injects `.next/types` imports.
- Web `tsconfig.json` no longer includes `.next/types/**/*.ts`. Including it
  races with a parallel `next build` that deletes `.next`.
