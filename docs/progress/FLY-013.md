**Decisions made, do not re-litigate:**

- Locale prefix is `always`, not `as-needed`. `/` goes through `src/proxy.ts` (Next 16 name for
  middleware) to `/pl`.
- `eslint-config-next` was **not** added. ESLint 10 is already wired in FLY-011;
  `eslint-config-next@16.3.3` is optional and FLY-013 stays under the line-count cap.
- pnpm 11 ignores dependency build scripts unless listed. `allowBuilds` in
  `pnpm-workspace.yaml` permits `@swc/core` and `@parcel/watcher` (Next native bindings).
  Without that, `next build` has no SWC binary.

**Watch out:**

- Message files live at the **repo root** (`messages/{locale}/common.json`), imported from
  `apps/web/src/i18n/request.ts` via `../../../../messages/...`. Do not move them into
  `apps/web` without updating that import.
- `@types/node` is pinned to **24.13.3**, not npm `latest` (26.x). CI runs Node 24.
- This branch is stacked on FLY-011. Merge #5 first.
